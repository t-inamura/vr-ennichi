# 50 m 四方を一周する、日本の縁日

四辺の通路を歩き、食品と遊びの屋台48店を巡るBlenderシーンです。中央に盆踊りのやぐら、周囲に提灯、休憩ベンチ、植栽を配置しています。

## 開く・歩く

1. Blenderで `ennichi_50m.blend` を開きます。地面と背景の画像素材はファイルに内蔵済みです。日本語看板はメッシュ化してあり、閲覧に日本語フォントの追加は不要です。
2. Outlinerで `80 | Cameras & lighting` を開き、`02 | Walk - sweets & games` を選択します。3Dビュー上で **Ctrl＋テンキー0** を押して、そのカメラを現在の視点にします。テンキーがない場合は **View → Cameras → Set Active Object as Camera** を使います。
3. 3Dビューの **View → Navigation → Walk Navigation** で歩行を開始します。**Shift＋`** はキーボード配列・設定に依存するため、メニュー操作が確実です。
4. **W / A / S / D** で前後左右、マウスで見回し、ホイールで移動速度を調節します。重力OFF時は **Q / E** で上下移動できます。左クリックで終了、Escで開始位置へ戻ります。ゲーム用の壁衝突判定はありません。

カメラビューから歩くとカメラ位置も変わります。元の構図を残す場合は、選択したカメラを **Shift＋D** で複製し、右クリックで元の位置に確定してから、複製側をアクティブカメラにしてください。動作が重い場合はビューポート右上を **Solid** 表示にし、仕上がり確認時に **Rendered** を使います。

操作参考：[Blender公式・Walk Navigation](https://docs.blender.org/manual/en/4.0/editors/3dview/navigate/walk_fly.html)

## 寸法と配置

| 項目 | 設計値 |
|---|---|
| 単位 | 1 Blender Unit = 1 m |
| 四角い周回路 | **中心線で一辺50 m、一周200 m** |
| 通路幅 | 6 m（中心線の内外に各3 m） |
| 内側の広場 | 約44 m四方 |
| 屋台 | 48店、各辺12店。基本区画は幅3.6 m × 奥行3.0 m |
| 屋台を含む規模 | 通路の外側に配置。屋台外端まで約63 m四方 |
| 外周植栽を含む規模 | 約90 m四方。背景用の地盤はさらに広く設定 |
| 中央やぐら | 床面約6 m四方、床高約1.35 m、屋根頂部6.65 m、提灯の支柱頂部7.75 m |

**50 mは敷地全体の外端ではなく、歩行ルート中心線の寸法です。** 四隅で通路がつながり、中央のやぐらへも歩いて近づけます。`site_plan.svg` は店舗番号・方向・寸法を記した案内図です。

## 編集と再生成

各屋台は独立したコレクションに入り、`STALL_01_cotton_candy` などの**親Empty**にまとまっています。店舗全体を移動・回転するときは親Emptyを選択します。やぐら、提灯、植栽、カメラは別コレクションです。店の種類や数は `build_ennichi.py` のリストと配置処理で変更できます。

再生成用ファイルは `build_ennichi.py`、`food_props.py`、`game_props.py`、`landscape.py`、`assets/` です。同じフォルダーに置き、そこをカレントディレクトリにして実行します。

```sh
blender --background --factory-startup --python build_ennichi.py
```

BlenderをPATHに登録していない場合は、`blender` を実行ファイルの絶対パスに置き換えます。再生成は同フォルダーの `ennichi_50m.blend` を上書きするため、手で編集した版は別名で保存してください。シーン生成スクリプトだけでは画像・動画を書き出しません。5枚の静止画は `blender --background ennichi_50m.blend --python render_views.py` で再生成できます。

日本語文字の**再生成**には日本語フォントが必要です。現在のスクリプトはmacOSのヒラギノ角ゴシックW6を探します。他OSでは `fontpaths` / `FONT` を利用可能な日本語フォントに変更してください。完成済みの `.blend` を開く場合は不要です。フォントファイル自体は配布しません。

## 見た目と素材

屋台、食品、ゲーム道具、やぐら、提灯、樹木は独自の手続き生成モデルです。縁日の実写写真を、紅白幕・看板・備品配置などのデザイン参考にしています。**参考サイトの店舗写真をテクスチャとして転載していません。**

地面と照明には次のCC0素材を使用し、`.blend` の保存時にパックします。

- 地面：[Poly Haven — Aerial Asphalt 01](https://polyhaven.com/a/aerial_asphalt_01)（Rob Tuytel）
- 背景照明：[Poly Haven — Kloppenheim 06 (Pure Sky)](https://polyhaven.com/a/kloppenheim_06_puresky)（Greg Zaal / Jarod Guest）
- [Poly HavenのCC0ライセンス](https://polyhaven.com/license)

形状・構成の参考：

- [アイプロダクション「おまつり縁日」](https://www.i-pro-spuj.co.jp/event/natsukashi-ennichi.html)
- [おおくまStyle「町民をつなげるイベント」](https://okuma-style.com/wmHYmKOu/QZm3tqUB)

写真撮影した店舗をスキャンしたモデルではありません。食品や樹木には手続き生成特有の簡略化があり、近接撮影ではその限界が見えます。人物・群衆・音・ゲーム操作・食品の購入動作・物理シミュレーションは含みません。

## 制作時の確認状態

Blender 5.2.2 LTSでシーン生成・保存・再読込を実施しました。48店舗・48種類、周回路200.0 m、メートル単位、画像素材の内蔵、日本語文字のメッシュ化を確認済みです。全景・通路・やぐら・食品の4枚は1600×1000 px、俯瞰は1400×1400 pxでCyclesレンダリングし、画像を目視確認しました。通路図と店舗一覧は生成スクリプトから抽出しています。確認値は `validation.json` に保存しています。ゲーム用衝突判定や人物動作は未実装です。
