# Unityデスクトップ実験の初期実装と研究ログの検証

既存の縁日モデルには実験の開始/終了、キーボード移動、訪問判定、端末内の研究ログ保存がないため、共同研究者が再現できるUnityプロジェクトと独立検証可能なログ中核を追加する。

2026-10-21に保存済みパッチから元コミット `efad6d996fc00767758ac9bd229080140919aa14` の実装を復元した。76ファイルのSHA-256と、GitHubへ登録した完全なツリーSHAの一致を確認済み。復元コミットは `1a37e9bc0c8fd5b24bdf945c42f85608bc86ce38`。元の実装と状況説明の更新を別コミットにしている。[復元記録](RESTORATION_2026-10-21.md) を参照。

- 初版の基準EditorはUnity 6000.0.65f1。現在の許容範囲は6000系正式版の6000.0.65f1以降（詳細は日本語手順）。builtinパッケージ宣言を固定し、Windowsを基本としmacOSビルド入口を用意。
- CharacterControllerの一人称移動、カメラ上下、匿名コード・条件入力、停止/再開/リセット/終了、フォーカス対策を実装。
- 実測単調時刻、独立したroot/camera pose、20Hz初期設定、状態/訪問イベント、ヒステリシスと中断時間の除外を実装。
- 追記journal、定期フラッシュ、終了時監査とCSV、保存失敗時の停止、未完了ログの復旧ツールを追加。
- マスターを保存しないBlender派生変換と専用Unity importer。共有meshのeffective material slotsを使用。形状確認用と静的照明ベイクを区別。
- GitHub Actionsの中核テストと、既存のライセンス付きクラウドrunner専用の手動Unity workflowを追加。

検証内容と実行証拠は `docs/VALIDATION.md`。2026-10-20にC#中核20件、別プロセス/相互監査3件、Python6件、Blender1件の計30件を実施した。今回の復元ではPython6件を再実行して成功。復元環境には.NET SDKがなく、C#・Blenderの再実行はしていない。GitHub Actionsの成否はPRチェックを参照する。Unityの実コンパイル・実機操作・描画性能・全体照明ベイク・Windows/macOS実行ビルドは未完了。HMD対応は未実装・未検証。
